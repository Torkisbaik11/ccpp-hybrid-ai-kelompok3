# Hybrid Intelligent System: Combined Cycle Power Plant Output Prediction (Kelompok 3)

Aplikasi Streamlit untuk prediksi daya listrik CCPP (UCI ID 294) menggunakan GA, PSO, MLP Regression, dan Fuzzy Logic.

## Cara Menjalankan Aplikasi
1. `pip install -r requirements.txt`
2. `streamlit run app.py`
